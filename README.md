# BuildTogether

BuildTogether is a web application project focused on helping people connect and collaborate.

## Features

- User registration and login interface
- User profile creation
- Browser-based data persistence using local storage

## Technologies

- JavaScript (ES6+)
- React and JSX
- HTML
- CSS
